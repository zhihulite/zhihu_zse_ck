# Go VM（wasm 内的字节码机）

站点 wasm 里有一台 Go 实现的字节码 VM：**10565 词**程序 + **104 项取指格式表** + **101 条常量池**。
它不是密码轮函数，是「取指 / 解码 / 派发」三层。

## 1. 取指与解码

- 程序按**词**编址：第 `pc` 词在内存里的字节偏移是 `pc << 2`。
- 每条指令的第一个词是**表索引**（0..103），查 104 项表得到 handler。
- 运行时分派表是 `table[b].f1 = [1, 104, 103, …, 2]`，即 **`elem = 1 if b == 0 else 105 - b`**。
- 指令长度按 elem 分 4 / 8 / 10 词；每个 elem 的长度唯一。
- 入口 `_00oooO` 拿到的是**自增前**的 pc。

机读产物：

| 文件 | 内容 |
|---|---|
| `out/prog.bin` | 10565 词程序（每词 1 字节） |
| `out/isa.json` | 104 个取指格式（elem → 派发器 + 操作数字段 + pc 步进） |
| `out/prog.listing.trace.txt` | 轨迹驱动的权威反汇编 |
| `out/pool_decoded.json` | 常量池 101 条明文 + 该 build 的 `(k0, xor)` |

## 2. 语义派发（35 个臂）

104 项表映射到 **35 个语义臂**，由 4 个派发器实现：

| 派发器 | 作用 |
|---|---|
| `_00oooO` | 主派发（35 个臂） |
| `_OOo0o0` | 二元/比较类 |
| `_O0O00o` | 取字面量 / 实参 |
| `_0OO0Oo` | slice 与栈操作 |

派发臂**不是 `word` 的函数**（同一 word 最多对应 16 个臂，依赖运行状态）。
对拍判据：`py/govm_semantics.py --verify` 用真机轨迹逐条比对「二级映射」，实测
**37313 / 37313 = 1.000000**。

## 3. 常量池

```
blob   = [00 00 <count:u16be>] <程序 count 字节> <tail>
tail   = [00 <len:u8> <密文>] × N          （101 条）
明文   = (c[j] ^ K[j]) ^ xor
K[0]   = k0 ;  K[j] = K[j-1] ^ p[j-1] ^ p[j-2]      (p[-1] := 0x22)
```

`(k0, xor)` **每 build 不同**，由池第 0 条恒为 Go 字面量 `"Go"` 唯一解出。

池内容（按索引）：

| 索引 | 内容 |
|---|---|
| #0..#5 | `"Go"` `"toString"` `"native"` `"__g"` `"ck"` `""` |
| #6 / #19 / #34 | 跨 build 恒定的 8-hex 常量 |
| #9 | **每 build 的 8-hex 常量** |
| #7 / #10 / #20 / #35 | 4 条 `005_…` 占位令牌（会话常量由此反推，见 `docs/RESTORATION.md`） |
| #11 | 跨 build 恒定的 64 字符表 |
| #15..#17 / #61 / #62 | 链式 XOR 密钥 |
| #23..#33 / #54..#58 | 环境探针源码（`return typeof …`） |
| #66..#97 | `rk[0..31] ^ 0x7B7B7B7B` 的十进制串 |
| #98 | 本 build 的 radix64 字母表 |

## 4. VM 结构体字段

`p0` = VM 指针，`l2` = 帧指针。常用偏移：

| 偏移 | 含义 |
|---|---|
| `p0+20` | 当前 pc |
| `p0+24` | 标志位 |
| `p0+276` / `p0+280` | 操作数栈的 tag / value |
| `p0+296` / `p0+300` | 寄存器组基址 / 栈长 |
| `p0+308` | 程序基址 |

Go 侧字段顺序与 JS 侧 VM 类的属性顺序**不同**，不能按顺序平移映射。

## 5. 复现

```bash
python py/pure_profile.py --static                    # 静态抠程序/池/取指表 + 自检
python py/govm_makecode.py --pool --out out/          # 解常量池
python py/govm_makecode.py --static-profile --wasm <build>.wasm --out out/
python py/govm_semantics.py --verify                  # 语义派发对拍真机轨迹
```
